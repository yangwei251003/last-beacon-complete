## 如何复现

在 `source/` 内执行：

```text
node --test tests/*.test.mjs
node build.mjs
```

浏览器证据位于项目工作区 `evidence/`；交付包 `validation/` 保留关键JSON结果和实际截图。浏览器自动化采用Chrome DevTools Protocol，模拟策略使用同一游戏规则，属于自动验证，不等同于人类逐章游玩评测。

## 范围与边界

这是包含完整菜单、8关战役、结局、沙盒和本机存档的可玩单机版本。八章共享岛形、道路和基座布局，通过供电容量、预告故障、敌潮、章节色调及植被变化形成不同场景；不宣称8张独立大型地图。

声音使用程序合成，并验证开关、音量和暂停相关路径；没有做真人听音评测或跨声卡响度标定。窄屏通过浏览器模拟检查，未在真实手机或多种GPU上做性能保证。专业模型是容量路由预算与能量守恒，绝非真实电压电流/潮流计算。

实际成品只使用程序化图形与原作MIT合成音效。研究中选出的CC0资源没有进入发行包，故不额外引入无用资产或外部下载依赖。

难度说明：三档难度均已通过确定性优化策略验证；尚未完成人类玩家的完整难度评测，不能据此声称困难模式对熟练玩家具有很高挑战。
